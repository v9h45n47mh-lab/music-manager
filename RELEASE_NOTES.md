# Music Manager 2.4.0

Favoriten am gemeinsamen Sortiergriff gedrückt halten und an die gewünschte Position ziehen. Auf-/Ab-Pfeile entfallen; Maus, Touch und Tastatur werden unterstützt. Die persönliche Reihenfolge wird einmal gespeichert. Bestehende Rechte, andere Benutzer und Wecklieder bleiben erhalten. HA UI Kit 1.7.0 lokal mitgeliefert.
